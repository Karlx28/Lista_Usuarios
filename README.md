# Lista de Usuarios con Spring Boot y Thymeleaf

Este proyecto es una aplicación web simple que muestra una lista de usuarios con sus respectivos datos: nombre, apellido y correo electrónico, hecha como práctica para uso de **Thymeleaf** en vistas HTML dinámicas dentro de un proyecto **Spring Boot**.

---

## Tecnologías utilizadas

- Spring Boot 3.x
- Thymeleaf
- Java 17
- Maven

---

## Instalación y ejecución

### Requisitos previos

- Tener instalado **Java 17** o superior.
- Tener instalado **Maven**.
- Un IDE o editor como **Visual Studio Code** o **IntelliJ IDEA**.

### Pasos para ejecutarlo

1. Clonar o descargar el repositorio.
2. Abrir una terminal en la raíz del proyecto.
3. Ejecutar:
   ```bash
   ./mvnw spring-boot:run
   ```
